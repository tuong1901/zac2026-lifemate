⚠️ Bẫy 1: Đoán mò 1 lần (One-shot)

Rủi ro: Ném toàn bộ câu lệnh vào LLM rồi bắt nó đoán tất cả tool calls. Sẽ sai nếu bước 2 phụ thuộc kết quả bước 1 (chưa search danh bạ thì không thể biết số điện thoại).

Giải pháp: Dùng ReAct Loop chạy từng bước trên ToolEnv.

⚠️ Bẫy 2: Tự ý bịa tham số bị thiếu

Rủi ro: Người dùng nói "Chuyển tiền cho Nam" mà Agent tự đoán số tiền 500k để gọi API ngân hàng → Bị 0 điểm.

Giải pháp: Xây dựng Validator phát hiện thiếu param bắt buộc để chuyển sang sys.ask_missing_info.

⚠️ Bẫy 3: Nghe nhầm tên riêng tiếng Việt

Rủi ro: ASR nghe "Sếp Dũng" thành "Sếp Dụng", "phòng khách" thành "phòng khác" làm hỏng toàn bộ chuỗi tìm kiếm.

Giải pháp: Kỹ thuật Dynamic Hotwords (trích xuất danh bạ/thiết bị từ state.json nhồi vào prompt ASR).

⚠️ Bẫy 4: Quá tải 147 Tools vào Prompt

Rủi ro: Nhồi 147 tools vào prompt làm LLM bị ngợp, suy luận chậm và gọi nhầm app người dùng chưa cài.

Giải pháp: Lọc Catalog theo installed_apps của từng mẫu (chỉ còn 5-10 tools).

env = ToolEnv(SPLIT, item["id"], root=DATA_ROOT)
while not finished and step < MAX_STEPS:
    action = llm.plan_next_action(user_text, context, tools_schema, previous_results)
    if action.is_missing_info:
        env.call("sys.ask_missing_info", action.params); break
    result = env.call(action.name, action.arguments)  # Real state update in memory!
return env.get_tool_calls(), env.get_state_hash()
